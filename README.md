# COL Academic Expo: Sleep Quality Research

Static website for the COL Academic Expo quantitative research project on sleep
quality, stress, depressive symptoms, and electronic device use among high
school students.

## GitHub Pages

After pushing this repository to GitHub, publish it with:

1. Open repository Settings.
2. Go to Pages.
3. Set Source to `Deploy from a branch`.
4. Select branch `main` and folder `/ (root)`.
5. Save.

The website will be available at:

`https://<github-username>.github.io/<repository-name>/`
